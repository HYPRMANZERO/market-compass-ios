# Market Compass development instructions

Before changing this repository, read [docs/PROJECT-STANDING-REQUIREMENTS.md](docs/PROJECT-STANDING-REQUIREMENTS.md). It is the **approved long-term product contract** for future project chats, specifically sections 2–4: Financial Pulse, evidence-backed Compass AI, and the P0–P3 engineering priorities.

Non-negotiable: Personal = everyday + all finance; Financial Advisor = finance only with protected server-side profile enforcement. Private inference remains on HYPRBOX. Do not post imported transactions without review, use guessed financial balances, expose credentials, or clear encrypted owner storage. Maintain both editions with Finance staged first and Personal promoted after tests; verify real live assets and do not confuse automated browser checks with physical iPhone acceptance.

Start with read-only `artifacts/market-compass/src/lib/financialPulseForecast.ts` and corresponding tests. Build actual dashboard or AI features only from approved data. Keep code, dependencies and new worktrees on D: and preserve existing C: junctions. The private backend and full guidebook are in the separate financial-advisor repository.
